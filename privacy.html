Outlook calendar sync

Privacy Policy

Last updated: September 16, 2026

Purpose and data processed

Outlook calendar sync transfers the owner's Exchange calendar events to the Google Calendar account selected during sign-in. It processes event identifiers, titles, dates, times, locations, descriptions, and participant display names for this synchronization. Attachments are not copied. Participants are not added to the Google event guest list.

The application uses the Google Calendar events permission to create, update, and delete synchronized copies and to check calendar access. It keeps a local record of the events it has synchronized so that subsequent changes can be applied to those copies. It is designed not to modify unrelated personal Google events.

Storage and transfer

Synchronization runs on the owner's Windows computer. Google authorization tokens, synchronization records, configuration, and diagnostic logs are stored in the local application folder. Logs can contain event titles and error messages. The saved Exchange password is protected using the Windows user's credentials. Google authorization tokens are stored in a local JSON file.

Calendar information is transferred between that computer, the configured Exchange server, and Google's Calendar service. The application has no separate synchronization server and does not send meeting invitations. Calendar information is not sold, used for advertising, or used to train AI models by this application.

Retention and control

Local authorization files and logs remain until the owner removes them. Copied events remain in Google Calendar unless removed by the owner or by the application's synchronization rules. Stopping the application or revoking Google access does not automatically delete previously copied events.

The owner can stop synchronization, remove the Windows autostart task, or revoke the application's access through the Google Account's third-party connections settings. The owner can also delete copied events in Google Calendar and remove local application data.

Google API data

Outlook calendar sync's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This website

These informational pages do not connect to calendars or collect meeting information. They contain no analytics scripts or sign-in forms. The pages are hosted on GitHub Pages.
