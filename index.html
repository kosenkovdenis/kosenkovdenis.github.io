Outlook calendar sync

A personal Windows application that copies events from the owner's Microsoft Exchange calendar to the owner's Google Calendar.

How synchronization works

The application runs on the owner's computer. It checks for changes every ten minutes while the computer and application are running and both calendar services are reachable.

It copies event titles, start and end times, locations, meeting descriptions, and participant display names. Names appear as text in the event description. Participants are not added as Google Calendar guests, and meeting invitations are not sent. Attachments are not copied.

Google Calendar access

Google Calendar access is used to create and update copies of Exchange events, remove tracked copies when the source event is removed or cancelled within the synchronization window, and check that the connected calendar is accessible.

The application requests the Google Calendar events permission for these operations. It does not request Gmail or Google Drive access.

Personal use

This application is maintained for its owner's personal use. It is not a public calendar synchronization service.
