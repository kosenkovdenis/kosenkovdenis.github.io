Политика конфиденциальности

Эта политика описывает работу настольного приложения Personal TaskBoard с данными Google Tasks. Приложение предназначено для личного использования владельцем Google-аккаунта.

Какие данные используются

После разрешения пользователя приложение получает списки и задачи Google Tasks, включая названия, описания, даты, статус выполнения, вложенность и служебные идентификаторы. Эти данные нужны, чтобы показать доску и выполнить действия пользователя.

Для обращения к Google API приложение использует учётные данные OAuth-клиента и токены доступа. Приложение не получает пароль Google и не запрашивает доступ к Gmail, Google Drive или Google Calendar.

Хранение

Данные задач загружаются в память работающего приложения и сохраняются непосредственно в Google Tasks. Локальная база задач и автономная синхронизация не используются.

Данные OAuth и токены входа сохраняются на компьютере и шифруются Windows DPAPI для текущего пользователя Windows. Локально также хранятся настройки окна и интерфейса.

Передача и использование

Настольное приложение обменивается данными задач напрямую с Google по защищённому соединению. Отдельный сервер разработчика для обработки задач не используется. Приложение не передаёт задачи рекламным или аналитическим службам, не продаёт их и не использует для обучения моделей искусственного интеллекта.

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отключение и удаление

В настройках Personal TaskBoard можно отключить аккаунт: приложение удалит локально сохранённые токены входа. Для полного отзыва разрешения нужно удалить доступ Personal TaskBoard в настройках подключений Google-аккаунта.

Отключение аккаунта не удаляет списки и задачи из Google Tasks. Удаление задачи или списка из приложения выполняет соответствующее действие в Google Tasks.
